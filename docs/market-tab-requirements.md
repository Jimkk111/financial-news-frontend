# 行情 Tab 页需求分析（股票数据展示）

> 文档定位：**需求分析**，回答"做什么、给用户什么、遵循什么业务规则"。接口设计、数据存储、图表库选型等"怎么做"不在本文档内，由开发阶段的技术方案另行确定。

## 一、背景与目标

### 背景

本产品是财经新闻平台，用户读到一条公司新闻后，无法回答"这家公司的股票现在什么价、今天涨了还是跌了"。行情是财经资讯场景的基本配套，也是本产品区别于通用新闻产品的差异化能力。

### 产品目标

1. 提供独立的「行情」入口：浏览 A股、美股、港股的主要指数与热门股票。
2. 查看任一标的的分时走势与日 K 线，满足基础行情阅读。
3. 建立行情基础能力，为下一阶段"新闻×行情联动"打基础。

---

## 二、用户与使用场景

目标用户：关注财经资讯的普通读者/个人投资者，无专业交易需求；**未登录也可完整浏览**。

| # | 场景 | 用户诉求 |
|---|------|---------|
| U1 | 早盘开盘后打开 App | 看今天大盘怎么样 → 打开行情 Tab 看指数涨跌 |
| U2 | 读新闻时想起某公司 | 想看这只股票今天走势 → 搜索名称/代码进入详情看分时 |
| U3 | 想回顾长期走势 | 切到日 K，缩放、拖动回看近几个月 |
| U4 | 夜里（北京时间）看美股 | 美股开盘中能看实时走势；休市时也能看最近一个交易日的数据 |

---

## 三、需求范围

### 本期范围

1. 主导航新增「行情」Tab。
2. 行情 Tab 页：三市场切换 + 主要指数卡片 + 热门标的列表。
3. 标的详情页：报价信息 + 分时图 + 日 K 线。
4. 标的搜索（三市场统一入口）。
5. 各状态（加载、空、错误）的完整用户体验。

### 明确不做（后续阶段另行立项）

| 不做 | 原因 |
|------|------|
| 新闻×行情联动 | 下一阶段核心功能，单独需求文档 |
| 自选股 | 依赖用户体系，先验证基础浏览价值 |
| 实时推送（WebSocket） | 本期定时刷新已满足浏览需求 |
| 复权切换、周K/月K、技术指标 | 首期日 K 默认前复权已满足基本阅读 |
| 美股盘前盘后行情 | 复杂度高、受众小 |
| 交易、资产组合、汇率换算 | 超出资讯产品定位 |

## 四、功能需求

### 4.1 行情 Tab 页

- **入口**：底部导航新增「行情」，与首页、AI助手、个人并列（第 2 位）；桌面端顶部导航同步新增。
- **市场切换**：A股 / 美股 / 港股 三段式切换；本次会话内记住用户最后所在的市场。
- **指数卡片**：每市场固定展示主要指数，横向排列。
  - A股：上证指数、深证成指、创业板指、沪深300
  - 美股：道琼斯、纳斯达克、标普500
  - 港股：恒生指数、恒生科技
  - 每张卡片：名称、最新点位、涨跌幅；可点击进入该指数详情页。
- **热门标的列表**：每市场约 20 只，每行展示名称、代码、最新价、涨跌幅；点击整行进入详情页。名单来源见 Q1。
- **加载策略**：各市场数据在首次切换到该市场时加载，切换回已加载过的市场不重新请求。

### 4.2 标的详情页

- **进入方式**：Tab 页列表项、指数卡片、搜索结果。
- **报价区**：名称、代码、市场标识、交易状态（开市/休市/午间休市/停牌）、最新价（大号展示）、涨跌额、涨跌幅、今开/昨收/最高/最低/成交量/成交额；金额按该市场币种符号展示。
- **分时图（默认视图）**：价格线 + 均价线 + 昨收基准线；下半区成交量柱；提供涨跌幅刻度参照。
- **日 K 图**：蜡烛图 + MA5/10/20/60 均线 + 成交量柱；默认展示约 120 个交易日；支持缩放与拖动回看历史。
- **图上取值**：点击/悬停显示该时点的日期、开高低收、涨跌幅、成交量、均线值；手机端信息展示不得遮挡手指操作区域。
- **自动刷新**：所处市场交易时段内约每 30 秒刷新；页面切到后台暂停刷新，回到前台立即刷新一次。
- **访问权限**：无需登录。

### 4.3 标的搜索

- 支持三种输入命中：证券代码、证券名称、名称拼音首字母（如 `gzmt` → 贵州茅台）。
- 三市场混合搜索，结果中标注所属市场；区分股票与指数。
- 输入即出联想结果；键盘 ↑↓ 选择、回车进入（移动端点选）。
- 无结果时给出明确提示。

## 五、业务规则

### 5.1 三市场展示规则

| 规则 | A股 | 港股 | 美股 |
|------|-----|------|------|
| 标的代码格式 | 6 位数字（如 `600519.SH`） | 5 位数字（如 `00700.HK`） | 字母代码（如 `AAPL.US`） |
| 交易时段（北京时间） | 9:30–11:30、13:00–15:00 | 9:30–12:00、13:00–16:00 | 21:30–次日 4:00（冬令时整体推后 1 小时） |
| 币种符号 | ¥ | HK$ | $ |
| 价格精度 | 2 位 | 最多 3 位（仙股 4 位），按数据原样展示 | 2 位 |
| 分时时间轴 | 240 分钟 | 330 分钟（午休断开） | 390 分钟 |

### 5.2 展示规则

1. **红涨绿跌**：统一采用 A 股惯例，三市场一致；平盘为灰色；不提供配色设置项。
2. 涨跌幅与涨跌额统一保留 2 位小数。
3. **休市展示**：休市时展示最近一个交易日的数据，并明确标注状态文案与数据日期，避免被误读为实时数据。
4. 美股仅展示正式交易时段数据，不含盘前盘后。
5. **指数与股票是两类标的**：同一数字代码可能既是指数又是股票（如 `000001` 既是上证指数又是平安银行），展示与跳转必须以完整标识区分，不得只按代码跳转。
6. 页面固定标注「数据仅供参考，不构成投资建议」。

### 5.3 数据新鲜度规则

- 交易时段内页面可见时自动刷新（频次见 4.2）。
- 数据出现延迟或获取异常时，**必须向用户明示**（如「数据延迟」提示），不得静默展示过期数据。
- 与第三方数据源的对接、容错、多源兜底由后端负责；对前端与用户呈现统一、口径一致的数据。（实现细节不在本需求内，此条仅界定前后端职责边界。）

## 六、异常与边界场景

| # | 场景 | 用户看到 |
|---|------|---------|
| E1 | 休市时段访问（含周末、节假日、美股收盘后） | 正常展示最近交易日数据 + 状态文案（收盘/休市）与数据日期，不报错、不空图 |
| E2 | 港股午间休市 | 状态显示「午间休市」，分时图保留上午数据 |
| E3 | 停牌 | 报价区「停牌」标识，图区给出说明，展示停牌前最后数据 |
| E4 | 退市标的 | 可搜索到并标注「已退市」，仅可看历史 K 线，无最新报价 |
| E5 | 新股/新指数历史不足 60 日 | 缺失的均线不绘制，页面不报错 |
| E6 | 除权除息日 | 日 K 默认前复权展示，走势连续可读 |
| E7 | 某一市场数据获取失败 | 该市场分段内提示失败并可重试，不影响其他市场分段 |
| E8 | 行情数据整体不可用 | 页面框架正常 + 明确错误提示 + 重试入口 |
| E9 | 搜索无结果 | 明确的空态提示，保留已输入内容 |

## 七、非功能要求

1. 首次进入行情 Tab，到列表内容可读 ≤ 2 秒（常规网络环境）。
2. 图表缩放、拖动操作流畅，无明显卡顿。
3. 亮色/暗色主题下均正常显示，切换即时生效。
4. 移动端与桌面端均可用。
5. 行情浏览接口为公开只读，需具备防滥用限流能力（约束后端）。

## 八、验收标准

- [ ] 底部导航出现「行情」Tab，未登录可访问 Tab 页与详情页
- [ ] 三市场切换正常，指数卡片点位与涨跌幅红涨绿跌着色正确
- [ ] 搜索 `600519` / `茅台` / `gzmt` / `00700` / `AAPL` 均命中对应标的，且结果标注市场
- [ ] 三个市场各抽一只标的核对详情页：币种符号正确（¥ / HK$ / $），价格与涨跌幅和主流行情软件一致（容差 ±0.01）
- [ ] 分时图包含价格线、均价线、昨收基准线、成交量柱；三市场分时点数符合各自时段
- [ ] 日 K 可缩放拖动，取值信息完整，移动端不遮挡操作
- [ ] 休市时段访问显示休市文案与数据日期；停牌标的展示停牌标识
- [ ] 亮/暗主题切换图表显示正常
- [ ] 单市场数据失败不影响其他市场，整体失败有重试入口
- [ ] 页面展示「数据仅供参考」声明；数据延迟时有明确提示
